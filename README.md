产品部数据分析工具 — 使用说明文档
版本：2026-10-15
适用对象：产品部人员
更新日期：2026-10-15
一、软件简介
本工具用于解析 ORT（On-going Reliability Test）老化测试日志，自动生成汇总 Excel 报表，减少手动整理工作量。
主要功能
1.老化 RMT 对比（量产）
2.老化 PROFILE 对比（量产）
3.单次 RMT 解析
4.单次 PROFILE 解析
5.检错信息汇总（量产 / 研发）
6.RMT 结果分析（CH 通道）（量产 / 研发）
7.测试时间收集（量产 / 研发）

二、启动软件
双击 产品部数据分析工具.exe 启动。
主界面结构
顶部工具栏：
分析阶段：选择"量产数据分析"或"研发阶段数据分析"
功能：选择具体功能
单次RMT / 单次PROFILE：快速入口
中间区域：功能页面（选择目录、执行按钮、进度条）
底部日志区：显示运行过程，关键信息有颜色区分
三、功能详解
功能 1：检错信息汇总
需求来源：
1.生产部门收集log解析后，会把生成的Excel表保存在log所在的文件夹里，现需要将所有解析后的Excel表进行汇总整理。
2.解析后的Excel表所在位置：1.T0时刻->pretest->EXT&SMT;2.每轮老化+检错->posttest->EXT&SMT
菜单路径：
量产：量产数据分析 → 检错信息汇总
研发：研发阶段数据分析 → 检错信息汇总
操作步骤：
1.点击"浏览..."，选择包含 T0 时刻文件夹的上层目录
例如：E:\Test_Tools\数据分析软件需求\量产ORT log\ROMT266051 ORT测试log
2.点击"🚀 开始检错信息汇总"
3.等待完成，弹窗提示输出路径
输出：
文件名：{目录名}_检错汇总_{时间戳}.xlsx
位置：与所选目录同级
内容：原检错表所有列 + 新增报错阶段列
检错数据分析要求的目录结构：


注意：
如果所有检错文件都无数据，输出一张只含表头的空表
功能 2：RMT 结果分析（CH 通道）
用途：按通道（CH）汇总多个时刻的 RMT 测试结果，计算 Min/Max/Avg，并对比不同时刻差值。
菜单路径：
量产：量产数据分析 → RMT结果分析（CH通道）
研发：研发阶段数据分析 → RMT结果分析（CH通道）
操作步骤：
1.点击"浏览..."，选择包含 T0 时刻文件夹的上层目录
2.（可选）填写 BIOS 版本号，留空默认 V25.06.00
3.点击"🚀 开始RMT结果分析（CH通道）"
4.等待完成，弹窗提示输出路径和详细日志路径
输出：
文件名：{目录名}_RMT-CH分析_{时间戳}.xlsx
位置：与所选目录同级
Sheet 结构：
Sheet 名	内容
T0_RMT（量产）	T0 时刻全部 RMT 数据 + Min/Max/Ave
T0-1_RMT、T0-2_RMT、T0-3_RMT（研发）	T0 时刻三次 RMT 各自数据 + Min/Max/Ave
结束时刻_RMT（量产）	结束时刻 RMT 数据 + Min/Max/Ave
结束时刻-1_RMT~ -3_RMT（研发）	结束时刻三次 RMT 数据
T0-CH0~ T0-CHn	T0 时刻所有 CH0~CHn 数据（含 Skt/Ch 列）+ Min/Max/Ave
结束时刻-CH0~ -CHn	结束时刻同上
差值对比	T0 与结束时刻的 Min/Max/Ave 差值

差值对比表说明：
每块含 3 行表格：Channel-min、Channel-max、Channel-Ave
每行对应 C0~C7
所有数据基于绝对值计算
差值 = 结束时刻 - T0 时刻
负数单元格填粉红色
左侧三块（T0 时刻/结束时刻/差值）合并单元格并填充颜色：绿/黄/橙
说明：
软件自动识别量产/研发的 RMT 目录结构，无需手动区分
详细日志保存在 logs/ 目录，路径在完成弹窗中显示
功能 3：测试时间收集
用途：收集每台服务器在每个测试子目录下的测试时间，汇总成一张宽表。
菜单路径：
量产：量产数据分析 → 测试时间收集
研发：研发阶段数据分析 → 测试时间收集
操作步骤：
1.点击"浏览..."，选择包含 T0 时刻文件夹的上层目录
2.点击"🚀 开始收集测试时间"
3.等待完成，弹窗提示输出路径
输出：
文件名：{目录名}_测试时间汇总_{时间戳}.xlsx
位置：与所选目录同级
时间格式：YYYY-MM-DD HH:MM:SS（Excel 日期时间格式）
说明：
loop 数自动识别
功能 4：单次 RMT 解析
用途：解析单个 RMT 目录下的所有日志，生成汇总表。
入口：顶部 单次RMT 按钮
操作步骤：
1.点击"浏览..."，选择包含 RMT 日志的文件夹（如 2.RMT）
2.（可选）填写 BIOS 版本，留空默认 V25.06.00
3.点击"🚀 开始RMT解析"
输出：
位置：{所选目录}\..\results\{上层目录名}_RMT_{时间戳}.xlsx
功能 5：单次 PROFILE 解析
用途：解析单个 PROFILE 目录下的所有日志。
入口：顶部 单次PROFILE 按钮
操作步骤：
1.点击"浏览..."，选择包含 PROFILE 日志的文件夹（如 3.profile）
2.点击"🚀 开始PROFILE解析"
输出：
位置：{所选目录}\..\results\{上层目录名}_PROFILE_{时间戳}.xlsx
功能 6：老化 RMT 对比（量产）
用途：对比两次 RMT 测试（所选目录下有两个RMT目录）的差异。这是用于比较老化前和老化后的RMT测试结果。
适用目录结构：

菜单路径：量产数据分析 → 老化RMT
操作步骤：
1.点击"浏览..."，选择包含两个 RMT 文件夹的上层目录
2.填写 BIOS 版本
3.点击"🚀 开始老化RMT对比"
输出：
文件名：{目录名}_RMT_{时间戳}.xlsx
Sheet：第一次RMT、第二次RMT、差值统计
说明：
软件自动找第一个和最后一个 .RMT 目录进行对比
差值超过第一次标准差时标红
功能 7：老化 PROFILE 对比（量产）
用途：对比两次 PROFILE 测试的差异。（所选目录下有两个PROFILE目录）
菜单路径：量产数据分析 → 老化PROFILE
操作步骤：类似功能 6
输出 Sheet：第一次Profile、第二次Profile、偏离百分比
四、目录结构要求
日志文件命名规范
{BMC_IP}_{日期}_{时间}.{扩展名}
例如：
192-168-10-91_2026-08-24_151845.log
192.168.10.91_2026-08-24_151845.xlsx
软件自动识别 - 或 . 作为 IP 分隔符。
五、操作小技巧
路径粘贴：可以直接在地址栏复制路径，粘贴到"浏览"输入框
批量运行：先跑检错汇总，再跑 RMT-CH，最后跑测试时间，互不干扰
日志查错：软件目录下的 logs/ 文件夹。文件名如 rmt_ch_20261013_103948.log。
程序出错时，把该文件发给开发人员排查。
输出位置：输出文件永远在所选目录的同级（不是内部），方便查找
时间戳：文件名带 _20261013_103948 格式的时间戳，多次运行不会覆盖
